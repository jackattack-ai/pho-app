# Pho Bò

Eine kleine Rezept-App für den iPhone-Home-Bildschirm. Basis ist das Pho-Rezept von Sarahs Tante aus New York.

- **Bestellen:** Sorte (Hähnchen, Rind nach Original, Tofu), Portionen, Nudeln und Extras wählen
- **Einkauf:** Einkaufsliste mit Mengen für die gewählten Portionen
- **Kochen:** Schritt für Schritt mit Timern
- **Original:** das Rezept der Tante, unverändert (Englisch und Deutsch)

Läuft offline, alle Daten bleiben lokal auf dem Gerät.
